### Scope qualifications

`Durable/resume` combines several mechanisms for discovery only; use the state summaries and [durability analysis](durability.md) to distinguish saved history, recovery and replay. Optional sandboxes are marked partial where backend or host selection determines isolation.

- **[DSPy](../harnesses/adjacent-frameworks.md)**: review_scope: Breadth-tier source review; unknown means not established here, not proven absent.; details: mcp_client=Tool adapter with optional MCP dependency. subagents=Ordinary module/tool composition. compaction=Trajectory truncation, not persisted summarization. os_sandbox=WASM/Deno interpreter is a language/runtime sandbox; no host OS confinement inferred.
- **[OpenClaw AI](../harnesses/openclaw.md)**: hooks: Provider/transport/host hooks only, not full agent lifecycle hooks.; plugins: Provider registration rather than the product plugin catalogue.
- **[Pi core (pi-ai + pi-agent-core)](../harnesses/pi-core.md)**: mcp_client: Optional pi-mcp sibling, not an agent-core dependency.; approvals: beforeToolCall can gate execution; host implements approval UI and policy.
- **[Vercel AI SDK core](../harnesses/ai-sdk.md)**: mcp_client: Separate first-party MCP package.; subagents: Agent-as-tool recipe; wrapped runtimes may provide native delegation.; durable_resume: Optional WorkflowAgent on external Workflow DevKit; core has no persistence and durability score is 1.; os_sandbox: Optional external sandbox providers; core does not isolate host tools.; web_ui: UI protocols and useChat bindings, not a finished application.
- **[Cline Agents](../harnesses/cline-kilo.md)**: plugins: Runtime hooks/extensions; full plugin distribution and services belong to core.; otel: Model-layer integration is optional; callbacks remain the basic observation surface.; approvals: Host callback is required when a tool needs approval; absent callback denies.
- **[Cline SDK / Core](../harnesses/cline-kilo.md)**: durable_resume: SQLite persistence and restore; no per-effect journal/replay verified.; os_sandbox: Unknown; plugin process isolation alone is insufficient evidence.; worktrees: Checkpoint restore verified, dedicated worktree allocation not established.; acp: Not established in this review.; mcp_server: Client integration verified; server mode not established.

## One-liners

- **[DSPy](../harnesses/adjacent-frameworks.md)**: Optimizable model programs and optional loops.
- **[OpenClaw AI](../harnesses/openclaw.md)**: Reusable model and streaming primitives extracted from the OpenClaw ecosystem, with isolated explicit provider registries and application-owned policy.
- **[Pi core (pi-ai + pi-agent-core)](../harnesses/pi-core.md)**: Provider layer plus a small in-memory loop; Pi v1 moved the experimental durable harness to a separate package.
- **[Vercel AI SDK core](../harnesses/ai-sdk.md)**: Provider-neutral generation/tool-loop primitives and UI streams; applications supply sessions, compaction and runtime ownership.
- **[Cline Agents](../harnesses/cline-kilo.md)**: Public host-neutral agent loop with supplied models/tools, lifecycle hooks, streaming and in-memory snapshots; coding tools, storage and teams belong to core.
- **[Cline SDK / Core](../harnesses/cline-kilo.md)**: Public coding-agent harness with sessions, default tools, MCP, plugins, teams and hub transports; @cline/sdk directly re-exports @cline/core.
- **[Deep Agents SDK](../harnesses/deepagents.md)**: Middleware, tools and backends assembled onto LangChain/LangGraph, with checkpoint durability configured through the underlying runtime.
- **[Flue](../harnesses/flue.md)**: Function-and-hook authoring over Pi, adding a durable conversation log and Node/Cloudflare deployment runtime.
- **[mini-SWE-agent](../harnesses/mini-swe-aider.md)**: A small inspectable loop whose environment seam makes it useful for experiments and benchmark runners.
- **[Pi Durable](../harnesses/pi-durable.md)**: A separate experimental task/checkpoint runtime over pi-ai, with explicit safe-versus-unsafe tool recovery.
- **[Pydantic AI Harness](../harnesses/python-frameworks.md)**: A real composable coding harness layered over Pydantic AI, with optional persistence and workspace isolation.
- **[smolagents](../harnesses/python-frameworks.md)**: A compact code/tool agent library; remote isolation and managed-agent composition have concrete compatibility limits.
- **[Strands SDK + harness](../harnesses/strands.md)**: Parallel Python/TypeScript SDKs with hooks, policy interventions and a harness factory; persistence is snapshot-based.
- **[DeepSeek Harness](../harnesses/deepseek-harness.md)**: A complete agent platform whose loop, providers, persistence and UI are composable Cordis plugins.
- **[FX / libfx](../harnesses/experimental.md)**: An experimental embeddable engine with unusually explicit durable-host contracts and idempotency requirements.
- **[Goose](../harnesses/goose.md)**: MCP-native Rust agent (CLI, Electron desktop, ACP HTTP/WS server) whose loop was just rewritten as a re-entrant, persistence-first state machine (goose-agent GDK crate) of 18 first-match Operations plus Inference over a SQLite-persisted conversation, with ~85 provider ids including other agents wrapped over ACP.
- **[OpenCode (V2)](../harnesses/opencode.md)**: Multi-client coding-agent service.
